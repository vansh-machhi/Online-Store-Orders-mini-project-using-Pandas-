🛒 Online Store Orders — Pandas Mini Project
📌 Overview

This project demonstrates an end-to-end data analysis workflow using Python, Pandas, and Matplotlib.
The goal is to analyze online store order data, generate business insights, create visualizations, and export results into multiple formats.

🎯 Objectives

-> Perform data cleaning and validation

-> Analyze sales and product performance

-> Group and summarize data

-> Create visual reports using charts

-> Save processed data for reporting

🧾 Dataset

The dataset contains:

OrderID

Product

Quantity

Price

Region

Calculated Field:

Total Revenue = Quantity × Price

⚙️ Technologies Used

-> Python

-> Pandas

-> Matplotlib

📊 Project Workflow
1️⃣ Data Cleaning

Checked dataset structure using info()

Verified missing values using isnull()

2️⃣ Data Analysis

Total sales by region

Most sold products

Revenue calculation

3️⃣ Visualization

Bar chart → Sales by Region

Pie chart → Product Share

4️⃣ Performance Optimization

Used vectorized operations

Avoided slow loops like iterrows()

5️⃣ Export Results

CSV file

Excel file

JSON file

📈 Output Insights

Regional sales distribution

Product performance analysis

Revenue trends
